# Portfólio — Daianny & Aline

Projeto desenvolvido em HTML, CSS e JavaScript para abrir e editar no Visual Studio Code.

## Como executar
1. Extraia o arquivo ZIP.
2. Abra a pasta `portfolio_daianny_aline` no VS Code.
3. Abra o arquivo `index.html` no navegador. Você também pode usar a extensão Live Server.

## Estrutura
- `index.html` — conteúdo e estrutura do portfólio.
- `css/style.css` — estilos e layout responsivo.
- `js/script.js` — interação do menu para celular.

O portfólio apresenta as estudantes, a escola, o curso técnico em Informática e os projetos de vida em Farmácia e Pedagogia.
